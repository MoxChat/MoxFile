# MoxFile Release Repository Rules

1. This repository contains MoxFile release artifacts and deployment documentation only.
2. MoxFile source, product specifications, and protocol design are maintained in the main Mox source repository.
3. Do not add Go source, database files, local caches, real `.env` values, tokens, or signing secrets.
4. Binary and LPK files must be generated by the main repository release workflow and match the documented version.
5. Deployment documents may describe configuration and operation but must not redefine the MoxFile protocol or retention contract.
